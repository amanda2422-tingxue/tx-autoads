隐私政策 服务条款
我们承诺：仅将数据用于广告管理和优化目的；不与第三方共享您的数据；遵守 Meta Platform Terms 和 Data Processing Terms；提供透明的数据使用说明。

1. 引言

AutoAds Platform（以下简称"本平台"、"我们"）是由 Zeydoo 开发的内部广告自动化管理工具。本隐私政策说明我们如何收集、使用、存储和保护您的个人信息。

2. 我们收集的信息

2.1 来自 Meta Marketing API 的数据

通过您授权连接的 Facebook 广告账户，我们收集：

  • 账户信息：广告账户 ID、商务管理平台信息、账户状态
  • 广告数据：
    • 广告活动（Campaigns）：名称、目标、预算、状态
    • 广告组（Ad Sets）：受众设置、版位、出价策略
    • 广告（Ads）：创意素材、文案、落地页
  • 表现数据：展示次数、点击次数、花费、转化数、CPA、CTR、ROAS
  • 受众数据：受众规模、定位参数（不含个人身份信息）

2.2 您直接提供的信息

  • 用户账户信息（邮箱、姓名）
  • 自动化规则配置
  • 素材标签和分类
  • 系统设置和偏好

2.3 自动收集的信息

  • 操作日志（创建、修改、删除记录）
  • 系统使用统计
  • 错误日志和诊断信息

3. 我们如何使用信息

3.1 核心功能

  • 广告管理：创建、编辑、监控广告活动
  • 数据分析：生成表现报告和趋势分析
  • 自动化优化：基于规则自动调整广告设置
  • 素材管理：组织、评分、迭代广告素材

3.2 具体用途

数据类型用途
广告表现数据计算 KPI、生成报告、优化决策
预算数据监控花费、自动预算调整
受众数据分析受众效果、优化定位
创意数据素材评分、A/B 测试、迭代优化

3.3 我们不会将数据用于

  • 出售给第三方
  • 用于您未授权的目的
  • 构建用户画像用于广告投放
  • 与 Meta 平台以外的服务共享

4. 数据存储和安全

4.1 存储位置

  • 数据存储在我们自有的服务器上
  • 数据库采用加密存储
  • 定期备份到安全的存储位置

4.2 安全措施

  • 传输加密：所有 API 通信使用 HTTPS
  • 存储加密：敏感数据（如 Access Token）加密存储
  • 访问控制：基于角色的权限管理
  • 审计日志：记录所有数据访问和修改操作

4.3 数据保留期限

数据类型保留期限说明
广告表现数据90 天用于趋势分析和报告
广告配置数据账户存续期间广告活动、素材信息
操作日志1 年审计和安全目的
自动化规则执行记录6 个月规则效果分析

5. 数据共享

我们不会将您的 Facebook 广告数据出售、出租或与第三方共享，除非：

  • 获得您的明确授权
  • 法律法规要求
  • 保护我们的合法权益

必要的服务提供商

我们可能使用以下服务提供商来处理数据：

  • 云服务提供商：用于服务器托管（如 AWS、阿里云）
  • 数据库服务：PostgreSQL 托管服务

这些服务提供商仅根据我们的指示处理数据，并遵守相应的数据保护协议。

6. 您的权利

您有权：

  • 查看我们持有的您的数据
  • 更正不准确的信息
  • 删除您的账户和相关数据
  • 导出您的数据

撤销授权

您可以随时：

  • 断开 Facebook 广告账户连接
  • 撤销 Meta API 授权
  • 删除您的平台账户

  • Meta Platform Terms
