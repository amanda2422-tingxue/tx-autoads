# 隐私政策

**生效日期**: 2026年4月20日

## 1. 引言

本隐私政策说明 AutoAds Platform（"我们"、"本平台"）如何收集、使用和保护您的个人信息。

## 2. 信息收集

### 2.1 我们收集的信息

- **账户信息**: Facebook 广告账户 ID、商务管理平台信息
- **广告数据**: 广告活动、广告组、广告的投放数据
- **使用数据**: 您在本平台的操作记录

### 2.2 信息来源

- **Meta Marketing API**: 通过授权获取您的 Facebook 广告数据
- **直接提供**: 您在使用本平台时主动输入的信息

## 3. 信息使用

我们使用收集的信息用于：

- 提供广告自动化管理服务
- 生成广告投放分析报告
- 优化广告投放策略
- 改进平台功能和服务

## 4. 信息共享

**我们不会出售您的数据给第三方**。

仅在以下情况下共享信息：
- 经您明确同意
- 法律法规要求
- 保护我们的合法权益

## 5. 数据安全

我们采取以下措施保护您的数据：

- 加密存储敏感信息
- 限制数据访问权限
- 定期安全审计
- 遵守 Meta 平台数据使用政策

## 6. 您的权利

您有权：
- 查看您的数据
- 更正不准确的信息
- 删除您的账户和数据
- 撤销 API 授权

## 7. 联系我们

如有隐私相关问题，请联系：
- 邮箱: privacy@yourcompany.com

## 8. 政策更新

我们可能不时更新本政策，更新后将通过平台通知您。
